# 1. PRIMARY GOAL

Create one comprehensive skill:

`omni-design`

The skill must intelligently decide what kind of design work is appropriate for the current task.

It must not impose one aesthetic on every project.

For example:

- an enterprise admin dashboard should not automatically become a flashy marketing website
- a public luxury website should not look like an internal CRUD system
- a banking form should prioritize clarity and trust
- a creative portfolio may use high visual variance
- an operations dashboard may require high information density
- a mobile app must respect touch ergonomics
- an existing product redesign must preserve useful product conventions
- Liquid Glass must only be used when contextually appropriate
- brutalism must not be selected merely because it is visually distinctive
- animations must support comprehension rather than exist as decoration

The skill must function as an adaptive design-intelligence system.
