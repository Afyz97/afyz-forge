# Audit template

```markdown
## System health check: [product or library]

### At a glance
Components checked: [n] | Problems: [n] | Score: [n]/100 (method: [how points were given])

### Naming
| Problem | Where | Suggested fix |
|---|---|---|

### Token use
| Token group | Tokens defined | Raw values found |
|---|---|---|
| Colour | [n] | [n] hardcoded hex (file:line list below) |
| Spacing | [n] | [n] arbitrary or off-grid values |
| Type | [n] | [n] one-off fonts or sizes |
| Radius / shadow / motion | [n] | [n] |

### Component coverage
| Component | States complete | Variants complete | Documented | Score |
|---|---|---|---|---|
| Button | yes | yes | partial | 8/10 |

### Fix first
1. [highest impact]
2. [next]
3. [next]
```

Use the shared severity scale when listing individual problems.
