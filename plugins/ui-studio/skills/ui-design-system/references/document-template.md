# Component documentation template

```markdown
## [Component name]

### Purpose
[what it is; when to reach for it; when not to]

### Variants
| Variant | Choose it when |
|---|---|

### Props
| Prop | Type | Default | Meaning |
|---|---|---|---|

### States
| State | How it looks | How it behaves |
|---|---|---|
| Default | | |
| Hover | | |
| Active / pressed | | |
| Focus-visible | | |
| Disabled | | not interactive; reason shown nearby (B2) |
| Loading | | spinner or progress; blocks double submit (B3) |
| Error | | |
| Empty (if it holds content) | | |

### Accessibility
- Role / element: [native element or ARIA role]
- Keyboard: [Tab, Enter / Space, Esc, arrows as relevant]
- Screen reader hears: "[announcement]"

### Use / avoid
| Use | Avoid |
|---|---|

### Example
[snippet in the project's stack: Blade / Flux / Livewire or React / Radix]
```
