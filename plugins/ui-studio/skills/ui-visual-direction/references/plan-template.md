# Pass 1 plan template

Fill this in before writing code. Keep it compact; it is a decision record, not a deck.

```markdown
## Visual plan: [screen or product]

### Subject
Product: [..] | Audience: [..] | This screen's one job: [..]
Vernacular to borrow from (materials, trade terms, artefacts): [..]

### Colour (4-6 named values)
| Name | Hex | Role |
|---|---|---|
| [e.g. Kiln] | #[..] | Primary action |
| [..] | #[..] | Surface |
| [..] | #[..] | Text |
| [..] | #[..] | Accent / status |

### Type
| Face | Role | Why this face |
|---|---|---|
| [..] | Display | [..] |
| [..] | Body / UI | [..] |
Scale: [ratio], base [16px]; steps [..]

### Layout options
A. [one sentence]
B. [one sentence]

    A                               B
    +---------------------------+   +---------------------------+
    | [ascii wireframe]         |   | [ascii wireframe]         |
    +---------------------------+   +---------------------------+

Alignment: [left / centred / justified per region, and why]

### The one loud thing (DP3)
[the element that carries personality; everything else stays quiet]

### Principles for this page
- [..]

### Self-review against the brief and AD1-AD10
| Choice | Default it resembles | Kept or changed | Why |
|---|---|---|---|
```

After the self-review, state what changed and why, then stop for approval.
