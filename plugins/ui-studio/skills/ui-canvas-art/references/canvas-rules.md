# Canvas rules

## Format and finish

- One page, heavily visual, unless more are requested. Gallery or magazine standard.
- Even for a film, game or book, keep it refined; never cartoonish.
- It should look like weeks of work by someone at the very top of the field.

## Visual language

- Build with repetition and precise shapes.
- Borrow the look of a field notebook from a science that does not exist: marks piled up by
  patient recording, patterns stacked in layers, sparse and clinical type, scale bars and
  reference ticks.
- Anchor the piece with one quiet phrase.
- Keep the palette small and coherent.

## Type

- Minimal and visual first; type is part of the artwork, not a caption on it.
- Match the volume to the subject: a punk gig poster can shout, a ceramics studio whispers.
  Most pieces want thin, light type.
- Use several of the bundled families where it helps; fetch more OFL fonts only when needed.

## Non-negotiable

- **No overlaps** between elements, ever.
- **Nothing outside the canvas**; consistent margins; every element has room to breathe.
