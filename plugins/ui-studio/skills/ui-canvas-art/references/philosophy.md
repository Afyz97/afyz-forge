# Writing the design philosophy

## Shape of the document

- **Name**: one or two words, like a movement ("Brutalist Joy", "Chromatic Silence",
  "Metabolist Dreams").
- **Body**: four to six substantial paragraphs. Cover, once each:
  1. space and form
  2. colour and material
  3. scale and rhythm
  4. composition and balance
  5. visual hierarchy
- **Craft**: repeatedly make clear that the work demands mastery: hours of careful
  adjustment, expert judgment, exacting finish. This sets the bar for step 3.
- **Openness**: write about the movement, not this specific piece, so the philosophy could
  produce many works.

## Example movements (short sketches; real documents run four to six paragraphs)

| Movement | Core idea | How it looks |
|---|---|---|
| Concrete Poetry | Monumental form, heavy geometry | huge colour blocks, sculptural type (one giant word against tiny captions), Brutalist divisions; think Polish poster design crossed with Le Corbusier |
| Chromatic Language | Colour carries the information | geometric fields of colour, minimal sans labels; Albers meeting data visualisation |
| Analog Meditation | Texture and silence | paper grain, ink bleed, wide empty space, barely-there type; the calm of a Japanese photobook |
| Organic Systems | Growth by modules and clusters | rounded forms, diagrams, icon-like marks, labels drifting in space |
| Geometric Silence | Strict order | exact grids, stark shapes, dramatic emptiness; Swiss formalism with Brutalist honesty |

Use these to calibrate ambition, not as templates.
