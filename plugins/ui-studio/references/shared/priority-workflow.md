# Priority order and workflow

The priority order, the mandatory workflow, the review and build output formats and "done
means" are owned by the user-first-ux skill.

Priority order and workflow: follow the **user-first-ux** skill if installed.
Minimum if not: honest > accessible > usable > efficient > consistent > aesthetic; Read → Report →
Plan → Approve (stop for approval) → Implement → Verify → Sync; name every trade-off in one line.

## What ui-studio adds to that frame

- **Distinctiveness** (`ai-defaults.md`) lives at level 6. It never overrides levels 1-5, but on
  the axes levels 1-5 leave open, a deliberate choice beats a reflexive one.
- **Plan**: for visual work the plan includes the token plan and the self-review pass from
  `ui-visual-direction`.
- **Verify**: after the user-first-ux checklist, run a critique pass (`ui-critique`) and the
  quality floor (`quality-floor.md`).
- **Build output**: insert "Token plan + wireframes (visual work)" between the IA outline and the
  implementation.
- **Severity**: `severity.md`.
