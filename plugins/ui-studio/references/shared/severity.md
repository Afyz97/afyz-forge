# Severity scale

One scale for every review, critique, audit and hook report, owned by the user-first-ux skill.

Severity: follow the **user-first-ux** skill if installed.
Minimum if not:
- **Critical** — stops a task or locks out a group of users.
- **High** — seriously degrades the experience or breaks a standard; most users notice.
- **Medium** — breaks a standard or rule with limited user impact.
- **Low** — polish.

Rank findings by user impact, not by the order you found them. Missing empty, error or loading
states are at least **High**. Ten Fixes pass / warn / fail are per-rule verdicts, not severities.
