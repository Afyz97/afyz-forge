# Notice

## Source studied

- **liquidslr/system-design-notes** - https://github.com/liquidslr/system-design-notes
  Chapter notes summarising *System Design Interview - An Insider's Guide*, Volumes 1 and 2, by
  Alex Xu and Sahn Lam (ByteByteGo). The notes repository did not include a license file when it
  was studied (October 2026).

## How this plugin uses it

- The notes were read in full and used as the subject-matter map: which problems to cover, which
  mechanisms matter, and the example numbers.
- All prose in this plugin is newly written and reorganised for agent use: decision tables,
  defaults, checklists, review workflows and a Laravel mapping that are not in the source. No
  passages, diagrams or images were copied.
- Facts and figures (latency numbers, Snowflake bit layout, example capacity estimates, geohash
  cell sizes, protocol and product names) are kept as facts. Where the source's arithmetic was
  wrong, the corrected value is used.
- Additional general knowledge (Bloom filters, stampede protection, rate-limit headers, Laravel
  features) comes from widely documented public practice.

For the full treatment of each topic, read the original books.
