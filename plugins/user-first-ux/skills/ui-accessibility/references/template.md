# Accessibility report template

```markdown
## Accessibility report: [page or component]
Standard: WCAG 2.2 AA | Date: [YYYY-MM-DD] | Scope: [pages, states] | Not verified: [list]

### Totals
Findings [n] | Critical [n] | High [n] | Medium [n] | Low [n]

### Findings
(one table per principle: Perceivable, Operable, Understandable, Robust)
| # | Problem | Criterion | Severity | Fix |
|---|---|---|---|---|

### Contrast measurements
| Element | Text colour | Background | Ratio | Needed | Result |
|---|---|---|---|---|---|

### Keyboard walk-through
| Element | Tab position | Enter / Space | Esc | Arrows |
|---|---|---|---|---|

### Screen-reader output
| Element | Announced as | Problem |
|---|---|---|

### Fix order
1. **[Critical]**: who it affects, what it blocks
2. **[High]**: what improves, for whom
3. **[Medium / Low]**: worth doing when nearby
```
